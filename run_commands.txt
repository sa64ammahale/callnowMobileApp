⚡ Compilation & Execution Commands

These are the primary commands you use while developing to run your app and update code on the fly.
• flutter run: Compiles and starts your app on a connected device or emulator.
• r (lowercase): Triggers Hot Reload. Updates the code changes into the Dart Virtual Machine and rebuilds the widget tree without restarting the app or losing its current state.
• R (uppercase): Triggers Hot Restart. Restarts the application completely, losing the current state, but is much faster than a full recompile.
• h: Displays the full list of interactive keyboard shortcuts available while an app is running in the terminal.
• q or c: Quits the current running application process and detaches the debugger.
• d: Detaches the CLI debugger but leaves the application running on the device.

🛠️ Development & Debugging

Use these commands to inspect your code, check performance, and set up your workspace.
• flutter doctor: Diagnoses your development environment. It checks for installed SDKs, tools, connected devices, and IDE plugins to ensure everything is set up correctly.
• flutter devices: Lists all physically connected devices, active emulators, and available web/desktop targets.
• flutter emulators: Lists all configured Android and iOS emulators on your machine. Append --launch <id> to start one.
• flutter logs: Displays the real-time log output of a running Flutter application.
• flutter analyze: Scans your project’s Dart code for syntax errors, warnings, and linter rule violations.

📦 Package & Project Management

These commands handle dependencies, project creation, and environment cleanup.
• flutter pub get: Fetches and downloads all the packages and dependencies listed in your pubspec.yaml file.
• flutter pub upgrade: Upgrades the packages listed in pubspec.yaml to their latest compatible versions.
• flutter create <project_name>: Generates a brand new Flutter project directory with default boilerplate code.
• flutter clean: Deletes the build/ directory and temporary cache files. Use this fix if your app is behaving strangely or failing to compile after changing dependencies.

🚀 Building & Releasing

When you are ready to ship your app to production, use these compilation commands.
• flutter build apk: Compiles a release Android Package (APK).
• flutter build appbundle: Compiles an Android App Bundle (AAB), which is the required format for publishing to the Google Play Store.
• flutter build ios: Prepares and builds the iOS application bundle (requires a Mac and Xcode).
• flutter build web: Compiles the application into highly optimized HTML, CSS, and JavaScript for web browsers.
